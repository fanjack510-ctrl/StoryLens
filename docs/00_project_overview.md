# 00｜项目总体方案

## 1. 产品定位

“叙镜 StoryLens”是一套面向小说作者、编辑与写作学习者的结构化拆书系统。系统将一本连续小说转换为可检索、可追溯、可比较的叙事知识库。

核心不是生成一次性摘要，而是建立：

- 书籍、章节、场景、叙事单元、原文证据的层级结构；
- 情节、钩子、人物塑造、场景描写等专项分析结果；
- 每条结论与原文段落 ID 的证据链；
- 可由本地模型与国内 API 共同执行的模型路由体系；
- 用户修正可沉淀为后续评测与训练数据。

## 2. 当前技术路线

开发阶段：

- 本地 Qwen GGUF + llama.cpp 为默认推理方式；
- API 接口保留，第一优先对接阿里云百炼；
- DeepSeek、智谱、Kimi 作为后续复核或备用 Provider；
- 不在第一阶段训练 LoRA；
- 不一次性把整本书交给模型；
- 先用规则和程序完成确定性处理，再调用模型。

## 3. MVP 核心能力

1. 导入 TXT、DOCX、EPUB。
2. 清洗文本，识别章节并生成稳定段落 ID。
3. 自动切分场景。
4. 提取事件因果链。
5. 识别开篇、场景和章尾钩子候选。
6. 提取人物描写案例。
7. 提取场景描写案例。
8. 所有结果均可回到原文证据。
9. 支持人工修正、重跑和导出。
10. 本地模型与 API 模型返回相同数据结构。

## 4. 成功标准

MVP 不是以“分析维度数量”验收，而以以下闭环验收：

- 同一章节可稳定重复解析；
- 所有原文引用真实存在；
- 单个分析任务失败不会破坏全书任务；
- 可单章、单场景、单维度重跑；
- 更换模型 Provider 不修改业务代码；
- 用户可以在 30 秒内定位到任一案例的原文上下文。
