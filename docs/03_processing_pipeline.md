# 03｜拆书处理流水线

## 1. 总流程

```text
导入文件
→ 计算文件哈希
→ 文本提取
→ 清洗与规范化
→ 章节识别
→ 段落编号
→ 场景候选切分
→ 边界复核
→ 专项分析器并行执行
→ 证据验证
→ 人工待审
→ 入库与检索
```

## 2. 确定性处理

优先使用程序完成：

- 文件读取；
- 章节标题识别；
- 空白与乱码清理；
- 段落编号；
- 字数统计；
- 文件哈希；
- 输出 Schema 校验；
- 证据范围校验。

## 3. 模型任务

### Scene Boundary

输入：相邻段落窗口。

输出：

- 是否切分；
- 边界段落；
- 时间、地点、视角、目标变化依据；
- 置信度。

### Scene Analysis

输入：完整场景。

输出：

- 进入状态；
- 目标；
- 阻力；
- 行动；
- 转折；
- 结果；
- 遗留问题；
- 证据段落 ID。

### Plot Chain

输出因果链，不得只输出章节摘要。

### Hook Analysis

区分候选钩子与已确认钩子。章尾钩子输入必须包含下一章开头的有限上下文。

### Character Portrayal

优先抽取动作、语言、物件、他人反应等间接塑造方式。

### Setting Description

判断环境描写对剧情、人物、氛围和伏笔的作用。

## 4. 重跑策略

- 文件变更：全量重建；
- Prompt 变更：仅重跑相关任务；
- 用户修正：保留原结果并生成新版本；
- Provider 切换：复用同一输入快照；
- 证据失败：先自动修复，再进入人工待审。
