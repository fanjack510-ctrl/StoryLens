# 08｜Codex 实施工作流

## 1. 分阶段执行

Codex 每轮只接受一个阶段任务，完成后必须提交：

- 实际读取文件；
- 修改文件列表；
- 新增依赖；
- 测试命令；
- 测试结果；
- 未完成项；
- 下一步建议。

## 2. 禁止行为

- 未读架构文档直接编码；
- 把所有功能塞进单文件；
- 直接在路由中调用模型；
- 在前端保存 API Key；
- 忽略异常与重试；
- 只写演示代码不写测试；
- 自动修改已有分析结果而不保留版本。

## 3. 代码质量

- Python 类型标注；
- Pydantic v2；
- SQLAlchemy 2.x；
- 服务层与路由层分离；
- Provider 适配器分离；
- 所有外部调用有 timeout；
- 日志不得输出原书全文和 API Key。

## 4. 完成定义

一项任务只有在以下条件全部满足时完成：

1. 代码可运行；
2. 测试通过；
3. 文档更新；
4. 错误路径有处理；
5. 无硬编码密钥；
6. 输出结果可复核。
