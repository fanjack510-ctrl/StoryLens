# Phase 2A.1 导入兼容与模型诊断

章节识别采用“候选提取—特征评分—程序采纳”流程。候选支持中文、全角和阿拉伯数字，以及章、回、节、可选空白和标点；评分综合行长度、行首、前后空行、编号连续性和文件内格式一致性。卷、简介、前言、番外、后记等特殊节单独识别，章节内容开始分界不会进入正文。

TXT 解码显式支持 UTF-8、UTF-8-SIG、GB18030 和 UTF-16 LE/BE，记录 BOM、换行、字节/行数、候选、最终章节、规则和最大章节规模。大于二十万字符仍只有一章、超过两千段或存在大量落选候选时保存 `CHAPTER_DETECTION_SUSPECT`，用户仍可确认导入。

导入前使用 `/books/chapter-detection/preview`；新导入书籍的源字节保存在被安全打包排除的 SQLite 中，以支持事务性 reparse。成功 AnalysisRun 存在时禁止破坏性替换。段落 API 在显式传入 offset/limit 时返回分页对象，limit 最大 500；旧的不带参数调用保持列表兼容。

自动分析 Provider 必须 enabled、非 manual-only 且实时健康检查为 healthy。模型控制 API 只调用项目内三个既有 PowerShell 脚本，只接受白名单 profile，不接受命令或可执行路径。AnalysisRun 另存根错误、失败阶段、Invocation、健康快照、可重试性和用户建议。

本机手工预览未复制源文件：检测为 GB18030、无 BOM、CRLF、4,992,603 字节，1256 个候选，最终 806 个章节/前置正文节；前十项从“正文”及“第一章那天，起了很大的雾”连续到“第九章去而复归又复归”。最大章节 6,342 字符、126 段，未触发单章节预警。
