# Phase 2B.3 相邻段落转换式边界

场景边界 v3.2 不再要求模型自由返回段落位置。程序为窗口中的每对相邻段落稳定生成
`T0001...Tnnnn`，每个候选明确包含 left 和 right 段落 ID。模型分类全部候选，程序仅把
通过业务规则且 `boundary_decision=true` 的 transition 映射为
`after_paragraph_id=left_paragraph_id`，因此最终 Scene、Artifact 与 API 保持兼容。

转换契约覆盖目标、行动链、时间、地点、视角、触发类型、持续变化、理由和证据。
非法或遗漏 transition、相互冲突的重复项、非法 Evidence 和分类字段矛盾均进入业务校验；
完全相同的重复项确定性去重。Invocation 只保存候选数量、选择/拒绝 ID、映射后的段落 ID
与契约版本，不保存正文。

真实条件式复验第一阶段执行了三个历史失败样本。物件触发目标变化通过；核心目标变化的
两次响应均达到 768 Token 并截断；时间跳跃响应结构合法，但旧版程序规则错误地把目标相同
作为强时间跳跃的全局否决条件。门禁按要求停止其余五组和完整 Run。该规则优先级与三样本
统计 StopIteration 已在离线代码中修复，但本轮没有追加收费请求，最终质量门槛仍未通过。
