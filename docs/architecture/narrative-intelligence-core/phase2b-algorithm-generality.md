# Phase 2B Algorithm Generality

## Ten principles

1. No rules added for a single novel
2. No special branches for a single chapter
3. No weights decided by a single work
4. No thresholds decided by a single work
5. Rules must apply across genres
6. Single instances only for discovery and verification
7. Tuning requires multi-work sample support
8. Must include degraded samples
9. Must include contrast samples
10. Must include metamorphic tests

## Allowed generic input differences

Length · chapter count · language · narrative order · viewpoint count · structural complexity · Provider context limit

## Forbidden triggers

Must not branch on book title, author, specific character names, or specific plot events.
