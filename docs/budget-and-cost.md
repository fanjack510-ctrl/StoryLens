# 预算与费用

## 普通模式你看到的

- 每日费用上限  
- 今日已用费用  
- 本章预计 / 最坏费用  
- 是否允许云端  
- 是否允许自动恢复  

请求次数、Token、重试等技术额度在 **设置 → 高级设置**（需开发者模式）中查看。

## 请求次数不足时

若本章完整分析最坏需要 N 次云端请求、今日剩余不足：

- 标题：「当前技术请求额度不足」  
- 展示 required / available / shortfall / estimated / worst_case  
- 主按钮：「按推荐额度创建任务」→ 使用 **Run 级临时授权**（`run_temporary_request_allowance`）  
- **不会**永久修改每日请求设置  
- **不会**擅自提高你设定的每日费用上限  

## 费用由谁支付

API 费用记在你的 **阿里云账户**。StoryLens 不代扣、不提供共享 Key。
