# StoryLens Online：香港内测基础阶段

## 范围

本阶段建立独立的线上运行边界，不修改 StoryLens 1.3.6 桌面安装版：

- 独立 `apps/online_api` 包；
- 独立 `infra/online` 部署栈；
- PostgreSQL 线上钱包与用量账本模型；
- 爱发电查询签名与订单响应校验；
- 计费倍率默认为实际模型成本的 `2.0`；
- 香港节点 HTTPS、PocketBase、PostgreSQL、Redis 基础编排。

本阶段不包含：

- 线上前端；
- PocketBase 用户登录页面；
- 充值到账事务；
- 现有拆书流水线接入 Worker；
- 正式服务器部署与域名配置；
- 版本号修改、桌面安装包构建或发布。

## 隔离约束

1. 不修改 `apps/desktop`。
2. 不修改 `apps/api/app` 的现有路由和 SQLite 模型。
3. 不读取桌面版 Windows/macOS 凭据。
4. 不改变离线 Pro 授权的向前兼容性。
5. 在线数据表统一使用 `online_` 前缀。
6. 在线配置拒绝 SQLite，避免误连桌面数据库。
7. 在线服务组件版本与根目录 `VERSION=1.3.6` 解耦。

## 计费口径

```text
模型实际成本 = 输入 Token 成本 + 输出 Token 成本
用户结算费用 = 模型实际成本 × 2.0
```

每次模型调用保留六位小数的费用账目，整本分析汇总后只进行一次分位向上取整，
避免多次调用被逐笔进位而偏离“实际成本的 2 倍”。结算单同时保留取整前费用和
取整差额，便于用户对账。

系统格式校验或平台故障引发的自动重试标记为 `platform_retry`，不向用户计费。
模型未成功产生可用结果时标记为 `provider_failed`，不向用户计费。价格条目必须记录
Provider、模型、输入/输出单价和定价版本，不允许在业务代码中假定固定Provider。

5. 在上述闭环稳定后接入线上前端。
