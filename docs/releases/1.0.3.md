- 统一版本管理
- **Opt-in updater**：自动检查；用户确认后下载；再次确认后安装；禁止默认自动下载/安装
- 设置页「版本与更新」手动检查/安装
- staging / stable 更新通道隔离

## 数据兼容

- SQLite schema：无破坏性迁移预期（相对 1.0.1 / 已装 1.0.2）
- 用户数据目录：`%LOCALAPPDATA%/StoryLens/` 保留
- 升级不得删除书籍、分析与配置

## updater 策略

- `automatic_check = true`
- `automatic_download = false`
- `automatic_install = false`
- 默认通道：`stable`
- staging 仅内部测试
- 同一公钥；禁止静默强制安装（本版本非强制安全更新）
