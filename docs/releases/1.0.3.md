# StoryLens 1.0.3 Release Notes

Status: **Unreleased**

## 用户更新说明

- 修复短片段与单句对白的场景边界巩固逻辑
- 优化授权文案、中文标签、流失风险说明与阶段指标表达
- 精简阅读旅程工具栏、修复设置遮挡并优化响应式布局
- 以 VERSION 为唯一来源统一版本同步与发布门禁
- 以 estimated 额度作为硬门槛，并完善设置页与分析弹窗额度入口
- 自动检查更新但不自动下载安装，保留用户确认与设置页手动入口
- 建立功能变更登记池、发布基线与下一版本自动汇总门禁
