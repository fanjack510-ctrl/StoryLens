# StoryLens 1.0.4 Release Notes

Status: **Unreleased**

## 用户更新说明

- 场景边界 PROVIDER_HTTP_ERROR 后可正确恢复：保留结构化错误、限制自动重试、修复并继续有反馈，且不再把阅读旅程未到阶段当作根因。
- 开发版启动后云端授权与 Provider 启用状态不再错误恢复为默认关闭；配置以后端持久化为唯一事实源。
- 建立 Reader Journey V2 通用规则规范与作品无关验证体系（对照/变形/退化/跨类型）；单篇小说仅作外部验证，不驱动调参。
- 将设置页从技术配置后台重构为普通用户可理解的渐进式设置界面，技术诊断收进高级/开发者区域。
- 在我的书库为每本书增加删除入口，二次确认后事务删除关联分析数据，不删除用户原始导入文件，运行中任务阻止删除。
- 增加正式本地网页版：浏览器访问本机FastAPI静态站，复用现有React与业务后端，数据与凭据仍在本机，保留Tauri桌面版并支持浏览器缩放。
- 增加爱发电离线签名授权码激活 StoryLens Pro 的首版流程，统一专业版文案与 entitlement 权限层。
- 将首次启动向导从三步压缩为欢迎+连接AI两步，匿名统计移出向导改为书库非阻塞邀请。
- 场景分析完成后自动衔接阅读旅程；统一单一 Book Workspace；书库打开直接进入第一章正文阅读。
- 系统整理最终场景划分，用户整体确认后继续分析，替代逐项候选审阅。
- Reader Journey出现非当前小说内容且错误结论绑定当前段落证据，暂停污染Artifact展示并加强来源指纹与校验。
- 将当前已完成的 UI、流水线、完整性与 Pro 授权等改动固化为 StoryLens 1.0.4 正式基线。

## 技术变更清单

- `CHG-20260721-010` (fix): PROVIDER_HTTP_ERROR (real incident: HTTP 429 rate limit on boundary_detection) lacked structured error persistence UX, unified recover never resumed boundary_detection (only incremented recovery_attempts), and skip journey check was shown as root failure. Added provider HTTP error snapshot fields/categories, capped auto(3)/manual(5) recovery, wired boundary checkpoint resume, and fixed recovery card feedback/copy.
- `CHG-20260721-011` (fix): Browser-dev uses repo ./data SQLite while packaged uses LOCALAPPDATA; shared Windows keyring made credentials look configured while cloud_enabled/provider switches read false from the isolated DB. AliyunForm also defaulted enabled=false before hydrate and could overwrite. Added config-profile API/banner, hydrate gates, and accurate RATE_LIMITED (429) messaging that preserves enablement flags.
- `CHG-20260721-012` (feature): Scene evidence validation: field classes local/holistic/hybrid; micro/short/medium_long bands; rationale+full-scene multi-factor overbroad; SCENE_BOUNDARY_TOO_BROAD before EVIDENCE_OVERBROAD_REUSE; evidence_remap_repair max 1 no level change; recovery UI drops misleading fix button for non-repairable business errors.
- `CHG-20260721-013` (improvement): Root causes: config vs real probe conflated; validation not persisted; missing validated_at; duplicate verify buttons; consent vs ready contradiction. Added ApplicationSetting ai_service_validation_snapshot + connection_ui_state machine; consent hydrates from SQLite.
- `CHG-20260721-014` (feature): Root: library had open-only UX; no DELETE API; analysis_runs lack book_id FK so orphans without explicit delete; imports are DB BLOBs not filesystem. Added delete_book transaction, active-task gate, OverflowMenu+confirm dialog.
- `CHG-20260721-015` (feature): Local web production SPA on :8765; uvicorn --ws none because product uses HTTP polling and websockets.exceptions import fails on incomplete install; Origin guard + instance lock; soupsieve remains non-blocking warning.
- `CHG-20260722-001` (feature): Ed25519 offline licenses with strict test/prod public-key isolation; production-only trust in formal runtimes; issuer scripts and release config checker.
- `CHG-20260722-002` (fix): Collapse first-launch wizard to welcome + AI connect; remove finish/telemetry step; add non-blocking library telemetry invite when consent UNKNOWN.
- `CHG-20260722-003` (fix): Scene pipeline no longer finalizes AnalysisRun; auto-enqueues Reader Journey on same run_id; Book workspace uses resolveWorkspaceLayout for mutually exclusive text|scene|journey tabs; WorkspaceJourneyPane replaces EmbeddedAnalysisResultShell for journey; remove independent-result CTA; progress+scene use grid not stacked shells. Revoke BookHomeCatalog intermediate page: /books/:id replace→first chapter view=reading; no auto analysisRun/result/Journey; top 章节目录 focuses left nav or opens drawer.
- `CHG-20260722-004` (fix): Introduce confirm_only boundary_review_mode, build_final_boundary_proposal, and ConfirmBoundaryDivisionPanel; product routes no longer use per-candidate BoundaryReviewPanel.
- `CHG-20260722-005` (fix): Graded Journey integrity: trusted/partially_trusted/legacy_unverified/data_integrity_failed; legacy without fingerprint shows with warning; soft claim heuristics only when fingerprint ok; severe wrong-book/context mismatch still blocks; field/scene redaction for partial.
