# StoryLens 1.0.5 Release Notes

Status: **Unreleased**

## 用户更新说明

- AI服务已配置且模式可选时，开始分析仍误报当前AI服务不支持此分析，导致无法启动分析。
- 纯正文阅读下左侧章节与中间正文被视口底部裁切、无法独立纵向滚动；此前长书导航补丁未修好该基础滚动。
- Reader Journey阅读动力曲线仅显示独立点、缺少折线连线，阶段卡数值正常但主曲线被拆成单点。
- 打开小说后左侧章节列表与正文区域未铺满视口底部，下方留白，章节与正文无法滚动到屏幕最下方。
- Reader Journey中问题链、钩子、回报与流失风险对同一叙事现象给出互相矛盾的解释，无法相互核对。
- Reader Journey曲线说明难懂、钩子回报被画成双分数线、节奏速度与适配混淆、技术字段外露，且metric URL不同步。
- NarrativeLoopView不一致时图表完全不画关系，用户只看到警告；需用多维度评估排出主解释并分级绘制，同时将流失风险改为阅读阻力。
- 普通用户难以快速理解曲线、节点与悬念回应关系；需统一通俗中文术语与说明，不改算法。
- 前端构建失败后仍用旧dist启动，导致实机看不到已提交的滚动与旅程界面修复。
- 场景卡几乎固定显示悬念/回应/阅读阻力；综合阅读含义不清；钩子回报图重叠；指标对比与全部指标/当前阶段等入口混乱。
- 钩子回收结果页信息过密：独立冲突提醒占用过大、暴露内部 ID 与英文技术日志，并与总览/清单重复。实机收口后只保留钩子总览与钩子清单，冲突降为轻量附加状态。
- 纯正文切章页面抖动；1291章长篇左侧标题换行压住下一章。
- 图表工具与 Lens 并列、紫色线含义不清、对比状态不可见、退出入口藏在菜单、阶段卡含义不清、适配全图用途不明。
- 修复六个 Lens 首次单击弹回：URL 单一可信源，lens/metric 原子更新，消除父级 syncUrl 竞态。
- 主题选择藏在设置页且刷新恢复默认；移到全局右上角并持久化。
- 将当前已完成的功能修复固化为 StoryLens 1.0.5 正式本地基线（安装包、Smoke、数据升级验证、本地 tag，不推送不公开发布）。
- 在书库/结果页「更多」中导出旅程 PNG 时，不再依赖已移除的图表更多操作菜单，直接触发导出。
