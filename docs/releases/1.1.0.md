# StoryLens 1.1.0 Release Notes

Status: **Unreleased**（本地构建与人工安装验收前草稿；尚未 GitHub Stable Release）

## 版本定位

StoryLens 1.1.0 是面向小说创作者的单章小说拆解与分析版本。

发布范围：**SINGLE CHAPTER ONLY**。

## 本版本包含

- TXT、DOCX、EPUB 小说导入
- 章节阅读与书库管理
- 场景边界识别与人工确认
- 单章结构化分析
- 单章分析进度与结果查看
- 已有任务重新进入
- 任务失败、取消、恢复与重试
- 模型配置、预算与费用控制
- 本地模型和云端模型配置能力

## 本版本修复（相对近期 RC 基线）

- 已完成单章任务正确进入结果页
- 进行中任务正确进入进度页
- 部分完成任务正确进入详情页
- 已存在任务冲突时自动进入原任务
- 修复本地模型选项加载期间被错误切换的问题
- 修复安装版 Sidecar 配置文件路径和任务恢复问题

## 暂未开放

- 原生全书概览
- 章节聚合洞察
- 独立读者旅程分析入口

这些能力仍在完善中，当前版本默认隐藏。直接访问全书相关路由时显示：该功能正在完善中，当前版本暂未开放。

## API Key 与隐私

- 用户需要在软件设置中填写自己的模型服务 API Key
- 软件不内置开发者个人的大模型 API Key
- 用户原始 TXT、DOCX 或 EPUB 文件不会被软件删除

## 不得宣称（本版本）

本版本不宣称当前支持：全书分析、全书总览、跨章节人物关系、全书钩子伏笔、全书读者旅程。
