# StoryLens 1.1.1

StoryLens 1.1.1 是一次稳定性和分析正确性修复版本。

Status: **Released**（正式 GitHub Stable Release）

发布范围：**SINGLE CHAPTER ONLY**。

## 本版本修复

- 修复 Reader Journey V2 节奏适配配置未正确进入安装包的问题
- 修复配置加载依赖启动目录的问题
- 修复配置加载失败后使用 `[0,100]` 默认区间，导致节奏适配分错误变为全 90 的问题
- 配置缺失、损坏或场景角色无法匹配时，系统现在会明确标记为无法判断，不再生成虚假的正常结果
- 增加配置版本、配置 Hash、加载来源和质量状态记录
- 修复节奏适配不可用时可能产生的错误诊断
- 增加无需重新调用大模型的确定性重派生能力

## 当前功能

- TXT、DOCX、EPUB 小说导入
- 章节阅读与书库管理
- 场景边界识别与人工确认
- 单章结构化分析
- 单章内部阅读旅程
- 分析进度、结果与任务重新进入
- 本地模型和用户自带云端模型配置
- 预算与费用控制

## 当前未开放

- 原生全书概览
- 章节聚合洞察
- 独立读者旅程入口

这些能力仍在完善中，当前版本默认隐藏。

## API Key 与隐私

StoryLens 不内置开发者个人的大模型 API Key。用户需要在软件设置中填写自己的模型服务 Key。

软件不会删除用户原始 TXT、DOCX 或 EPUB 文件。
