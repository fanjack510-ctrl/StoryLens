# StoryLens 1.3.1 Release Notes

Status: **Released on 2026-08-25**

## 下载与安装

- Windows x64 安装包：`StoryLens_1.3.1_x64-setup.exe`
- SHA-256：`33279f33fd409e9972fe4ba1429fd5d0f5dae32bb19c0de110a7abc795a5682a`
- 本版本未配置 Windows 代码签名与 Tauri 更新签名；Windows SmartScreen 可能显示未知发布者提示，应用内自动更新暂不启用。
- 安装包不包含本机 `.env`、API Key、授权私钥、用户数据库或本地参考语料。

## 发布安全修复

- 将 `react-router-dom` / `react-router` 升级到 `7.18.2`，生产依赖审计结果为 0 个已知漏洞。

## 用户更新说明

- 修复版本升级后，历史台账债导致后端契约测试错误断言旧版本号的问题。
- 统一功能入口，按书籍类型过滤可用读法，去除重复章节动作与未接线的素材迁移半成品，并提供可直接验收的本地预览。
- 素材库不再展示写作方法论，改为按题材沉淀可检索、可溯源的领域知识。
- 增加全局知识库入口，把多本小说与工具书整理出的知识集中搜索、筛选和溯源。
- 让自动验收准确覆盖当前正式全书分析页面，避免已下线旧页面造成假失败。
- 让已完成的共性视图被前后端能力系统一致识别，不再落入未知功能状态。
- 恢复正式 API、预算、Provider 边界和本地启动保护的可信自动验收。
- 后端测试可以从项目根目录稳定运行。
- 书库首页升级为仪表盘，并让画像与付费能力入口始终可找到。
- 长篇分析不再把全书正文重复写入每章资产，付费有效期内的新能力可正确解锁。
- 素材库完成本地引擎、数据表、路由、测试和浏览界面的基础迁入。
- 旧私有 Lab 回放不再阻塞正式产品验收，正式全书 V2 的证据与执行上下文安全门保持不变。
- 书库从放大的列表重排为真正的首页：先看书库现状与最近工作，再进入完整书单；全局顶栏同时缩短。
- 题材知识库改为独立全局页面，只从已完成全文拆文的小说提取素材；单本书不再出现提取素材入口。
- 单章分析恢复可编辑的场景边界工作台；阅读页只显示单章分析，评测与拆文统一放到独立的全书分析页面选择。
- 当前本地开发环境已激活隔离的 StoryLens Pro 测试授权，并可直接验证共同套路、找参考和 PDF 导出。
- 进入场景确认页时会稳定显示准备中状态，待最新划分数据返回后直接进入确认界面，不再闪现无需确认的误导提示。
- 长篇小说会先完成作品画像确认，再清楚选择单章精析或全书分析；两种范围不再被做成主入口和隐蔽小链接。
- 短篇拆文现在可直接导出真实PDF，并与全书、单章共享同一套Pro授权和错误提示。
- 将工具书读懂结果整理为全书总览、可带走内容、适读人群、章节导航和可折叠逐节详情，去除裸露格式标记与重复页面标题。
- 知识库拆分为素材知识、榜单共性和作品Skill三个工作区；素材以知识结论优先展示，并可从全文拆解报告生成可下载的SKILL.md。
- 把旧项目的40967条派生素材安全迁入独立知识层，并在知识库统一检索。
- 清除错误导入的素材数据，在空库状态下仍保留题材与分类目录，等待重新导入原始素材。
- 全文小说素材按固化题材目录提炼，经过阶段限制、全书去重和数量上限后再进入知识库。
- 知识卡不再使用重复套话，而是展示分类命中的真实证据句并与原文依据一一对应。
- 从少量高置信参考小说中深读真实段落，经按题材语义提炼、质量终审和逐事实证据审计，为十个固定小说类型沉淀可直接用于创作的纯知识素材。
- 将五册古代种田文写作资料按纯知识原则补入种田知识库，并保留生活依据、可直接写和避坑三段可展开资料依据。
- 将长书单改为可搜索、可筛选的独立滚动区，并让比较篮子与开始按钮始终在桌面视野内。
- 将跨书检索改为找参考，并把免费原句定位与 Pro 相似写法拆成两个清晰入口，结果可返回原书核对。
- 将大量全文来源收进可折叠、可搜索、可按状态筛选并分页的管理器，避免来源列表持续推低知识目录。
- 在榜单共性结果中增加 Pro 结构化 PDF 导出，完整保留比较范围、共同手法、逐书依据和独有做法。
- 免费版保留完整分析闭环；Pro 解锁全书素材提取、作品 Skill、榜单共性、找参考和结构化 PDF，并通过爱发电授权码离线激活。
- 发布预览和冻结只校验当前基础版本之后的变更，历史版本记录继续保留但不再阻塞新版本。
