# StoryLens 1.3.3 Release Notes

Status: **Released**

## 用户更新说明

- 设置页及功能内的爱发电购买入口会使用系统默认浏览器打开，并在打开失败时给出准确提示。

## 技术变更清单

- `CHG-20260825-014` (fix): 正式配置中的爱发电 URL 已正确随 sidecar 打包；故障来自 Tauri WebView 使用 window.open/target=_blank。新增经过 HTTPS 与本地地址安全校验的原生 Tauri 命令，Windows 下通过 ShellExecuteW 调用系统默认浏览器；浏览器开发环境保留 window.open。新增统一 ExternalUrlLink，覆盖设置、短篇 PDF、全书 PDF、读者旅程、榜单共性、跨书检索和能力页入口，并区分地址缺失与系统打开失败提示。
