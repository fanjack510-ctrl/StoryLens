# StoryLens 1.3.6 Release Notes

Status: **Unreleased**

## 用户更新说明

- 为 Apple Silicon 与 Intel Mac 提供 1.3.4 DMG 构建，并补齐本地服务、数据目录、外链与 PDF 浏览器的平台适配。
- 所有分析报告的 HTML 可在安装版可靠保存，并调整为基础阅读版；Pro PDF 保留结构化成品报告。
- AI 设置中的连接测试会先保存当前服务商、模型、接口地址和 API Key，再使用已保存配置执行诊断与真实最小调用。
- 修复安装版点击导出 PDF 后出现 Failed to fetch、没有生成文件的问题。

## 技术变更清单

- `CHG-20260827-001` (build): 新增双架构 macOS GitHub Actions 构建、PyInstaller sidecar/DMG 冒烟门禁，并使数据目录、sidecar 生命周期、外部购买链接和 Chromium PDF 查找跨平台。
- `CHG-20260828-001` (fix): 将全书、短篇、读懂和单章 HTML 导出统一接入 saveBlobAsFile；新增四种基础阅读版生成器；Pro PDF 保留结构化报告；PDF 失败不再静默降级为同内容 HTML；所有入口显示保存结果或真实错误。
- `CHG-20260828-002` (fix): 重构 AiConnectionPanel：抽出持久化事务；连接测试严格等待 Provider 配置 PUT 与当前 Provider 保存成功后，才执行 transport-diagnostic 和真实最小调用；仅保存不再自动联网；无密钥时禁用测试；切换 Provider 重置旧表单状态。
- `CHG-20260829-001` (fix): 修正 Edge 启动器向子进程交接时被误判为退出的问题；通过 CDP 主动关闭浏览器；按进程树清理专用打印进程；临时目录锁清理改为有界重试且永不遮蔽 HTTP 错误；CLI 回退使用隔离 profile 并等待异步输出文件；CDP 错误写入日志。
