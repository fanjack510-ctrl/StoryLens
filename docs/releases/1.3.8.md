# StoryLens 1.3.8 Release Notes

Status: **Unreleased**

## 用户更新说明

- 确保场景边界确认只作用于当前单章分析任务，避免旧任务与新任务交叉导致反复确认。
- 修复目录条目误判正文、引言与后记等结构单元漏切，以及末章吞入附属材料导致异常膨胀的问题。
- 修复含已完成全书快照的书籍无法从桌面书库删除的问题。

## 技术变更清单

- `CHG-20260917-001` (fix): Scene boundary review is now scoped by analysis_run_id across overview, draft, split, save, restore, confirm, discard, and diff calls. The server validates Run/Chapter/Revision ownership and confirmation only supersedes revisions and journeys from the same AnalysisRun; legacy chapter-only reads remain compatible.
- `CHG-20260920-001` (fix): Import now parses the whole document through normalized paragraph evidence, heading candidates, explicit and implicit TOC detection, global sequence resolution, typed unit boundaries, structure validation, and conservative oversized-unit repair. DOCX style metadata is retained. Analyzable routing counts introduction, chapters, and afterword while excluding front matter, notes, acknowledgements, and references. EPUB navigation documents are excluded from readable content, and heading-only structural units remain diagnostic-only instead of entering the legacy Chapter table. Comprehend now reads every analyzable chapter from the immutable snapshot bound to the run, so DOCX files without standard Heading styles cannot collapse into one front-matter section.
- `CHG-20260920-002` (fix): Delete immutable book snapshots before their live source chapters so SQLite does not invoke ON DELETE SET NULL updates rejected by completed-snapshot immutability triggers.
