# 跑通第一次分析

前置：已配置 Qwen，且已导入并打开章节。

## 推荐流程

1. 点击「开始分析」。  
2. 阅读预算预检：请求 / Token / 费用是否充足。  
3. 若仅请求次数不足（例如最坏 66、剩余 59）：  
   - 会看到「当前技术请求额度不足」  
   - 可「按推荐额度创建任务」（**仅本次 Run 临时授权**，不永久改每日请求上限）  
4. 确认云端同意后创建任务。  
5. 完成场景边界人工审阅。  
6. 等待 Scene Analysis，再生成 Reader Journey。  
7. 在旅程工作台查看 Phase / 曲线 / Inspector / Evidence。  
8. 导出 PNG / JSON / Markdown。  

## 普通模式

- Provider 固定为阿里云百炼 · Qwen  
- 本地模型与其他云端档位需开启开发者模式  

若分析暂停，请看 [恢复](recovery.md) 与 [预算与费用](budget-and-cost.md)。
