# 故障排查

| 现象 | 建议 |
|------|------|
| 无法启动 | 先 `.\scripts\bootstrap.ps1`，确认 `.venv` 与 Node 可用 |
| 前端打不开 | 确认 `.\scripts\start-dev.ps1`；后端 `http://127.0.0.1:8000/health` |
| 提示未配置 AI | 打开设置 → AI 服务，完成 Qwen 向导 |
| 创建任务发灰 / 额度不足 | 阅读页面内预算说明；用「按推荐额度创建」临时授权，勿盲目改高级请求上限 |
| 分析暂停 | 使用「修复并继续」；查看是否聚合了多个阻塞 |
| 连接测试失败 | 检查网络、Key 权限、云端开关；诊断详情仅作技术参考 |
| 测试失败 | `.\scripts\check-project.ps1` |

不要把真实 API Key 粘贴到 Issue、截图或审计文件中。
