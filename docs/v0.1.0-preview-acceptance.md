# StoryLens v0.1.0 Preview 人工验收清单

本文档用于正式发布前的人工走查。自动化构建与 smoke 结果见集成 commit 说明；未在本机执行的项标记为 **待验证**。

## 安装

- [ ] 双击 NSIS 安装包完成安装（路径见 release 构建输出）
- [ ] 目标机器 **无** 预装 Python / Node.js 仍可运行
- [ ] 日常使用 **无** 黑色命令行窗口常驻
- [ ] 首次启动后本地后端 / sidecar 自动就绪（设置或分析可用）
- [ ] 退出应用后 sidecar 进程结束（任务管理器确认）
- [ ] 用户数据写入 `%LOCALAPPDATA%\StoryLens`
- [ ] 卸载后重装，书库与配置仍保留（同用户配置目录）

## 配置

- [ ] 首次向导 **不超过三步**（欢迎 → AI → 开始使用）
- [ ] 普通用户主路径只需配置 API Key（高级 Provider 默认隐藏）
- [ ] 分析模式默认「均衡」或产品既定默认
- [ ] 高级设置默认折叠 / 隐藏
- [ ] 「测试连接」失败时展示 **中文** 可读错误（非原始堆栈）

## 隐私

- [ ] 默认 **不** 发送匿名统计（同意状态 UNKNOWN / 关闭）
- [ ] 仅在用户明确开启后发送事件
- [ ] 设置中关闭后立即停止新事件
- [ ] 事件与 UI 说明均 **不** 包含：小说正文、书名、章节标题、本地路径、API Key
- [ ] 普通用户界面 **不** 出现 PostHog 等底层平台名称

## VIP

- [ ] 设置显示当前为 **免费版**
- [ ] VIP 购买 / 激活显示 **即将开放**
- [ ] **正式** 构建无法通过 DEV Mock 伪造激活成功
- [ ] 现有分析、导入、阅读功能 **不受** VIP 门禁限制

## 更新

- [ ] 设置中「检查更新」失败 **不影响** 本地分析
- [ ] 无签名密钥时 **不** 生成伪签名更新包
- [ ] 从 GitHub Release 的真实增量更新：**待验证**（需生产密钥与发布渠道）

## 遥测事件（开发核对）

- [ ] `app_launched`：同意且 API 就绪后每会话至多一次
- [ ] `analysis_started`：任务创建成功后
- [ ] `analysis_completed`：任务 succeeded / failed / cancelled 终态
- [ ] `feature_used` / `update_installed`：**尚未接线**（预期无事件）

## GUI 未自动化项

- [ ] 安装向导 UI 与卸载入口
- [ ] 系统托盘（如有）与多窗口行为
- [ ] 高 DPI / 缩放下的布局
- [ ] 离线环境下的首次启动与错误提示
