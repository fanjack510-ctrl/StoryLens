# StoryLens 1.1.0

StoryLens 1.1.0 是面向小说创作者的单章小说拆解与分析正式版本。

## 当前功能

- TXT、DOCX、EPUB 小说导入
- 章节阅读与书库管理
- 场景边界识别与人工确认
- 单章结构化分析
- 单章内部阅读旅程
- 分析进度、结果与任务重新进入
- 本地模型和用户自带云端模型配置
- 预算与费用控制

## 本版本修复

- 修复阅读旅程异常导致本地服务退出的问题
- 修复重启后阅读旅程长期假运行的问题
- 修复阅读旅程状态、进度和任务操作不一致
- 修复过期失败响应覆盖正常进度或完成结果
- 修复已完成任务错误进入进度页
- 修复部分完成任务操作错误
- 修复本地模型选项加载状态问题

## 当前未开放

- 原生全书概览
- 章节聚合洞察
- 独立读者旅程入口

## API Key与隐私

StoryLens 不内置开发者个人的大模型API Key。
用户需要在软件设置中填写自己的模型服务Key。

软件不会删除用户原始TXT、DOCX或EPUB文件。
