# StoryLens 1.1.1

StoryLens 1.1.1 是一次稳定性和分析正确性修复版本。

## 本版本修复

- 修复 Reader Journey V2 节奏适配配置未正确进入安装包的问题；
- 修复配置加载依赖启动目录的问题；
- 修复配置加载失败后使用 `[0,100]` 默认区间，导致节奏适配分错误变为全 90 的问题；
- 配置缺失、损坏或场景角色无法匹配时，系统现在会明确标记为无法判断，不再生成虚假的正常结果；
- 增加配置版本、配置 Hash、加载来源和质量状态记录；
- 修复节奏适配不可用时可能产生的错误诊断；
- 增加无需重新调用大模型的确定性重派生能力。

## 分析规则说明

本次修复是适用于所有作品和章节的通用规则修复，
没有针对某一本小说、某一章或某个 Run 添加特殊判断。

节奏速度、场景角色、张力、钩子和情绪的模型分析规则没有改变。

## 历史结果说明

StoryLens 1.1.1 不会在启动时自动改写已经生成的历史分析结果。

- 1.1.1 之后新生成的 Reader Journey 会直接使用修复后的配置和派生规则；
- 1.1.0 已经生成的结果会继续保留原始状态；
- 用户重新分析对应章节后，会使用当前版本规则生成新结果。

## 当前功能

- TXT、DOCX、EPUB 小说导入；
- 章节阅读与书库管理；
- 场景识别与人工确认；
- 单章结构化分析；
- 单章内部 Reader Journey；
- 任务中心、进度查看和结果重新进入；
- 用户自带云端模型配置；
- 本地模型配置；
- 预算和费用控制。

## 当前未开放

- 原生全书概览；
- 章节聚合洞察；
- 独立 Reader Journey 入口。

## API Key 与隐私

StoryLens 不内置开发者个人的大模型 API Key。
用户需要在软件设置中填写自己的模型服务 Key。

StoryLens 不会删除用户原始的 TXT、DOCX 或 EPUB 文件。
