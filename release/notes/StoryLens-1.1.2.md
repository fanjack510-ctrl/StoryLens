# StoryLens 1.1.2

StoryLens 1.1.2 是一次 Hotfix 稳定性与体验修复版本（基于 v1.1.1）。

## 稳定性修复

- 修复大模型结构化输出触顶后重复使用相同限制的问题；
- 支持候选分批处理和自适应输出预算；
- 改善任务进度和实际用量展示。

## 场景边界人工校正

- 场景分析完成后可移动、增加、删除和合并场景边界；
- 支持场景排除；
- 人工确认后按新场景重新生成阅读旅程；
- 保留未变场景结果，重新分析发生变化的场景。

## 阅读旅程界面优化

- 六个维度洞察更简洁；
- 开端、发展、收束阶段颜色贯通；
- 综合阅读增加推动因素、拖累因素和关键节点；
- 剧情推进、阅读张力、情绪强度、节奏速度增加节点判断；
- 单章钩子分析改为「提出、回应、继续保留和章末牵引」。

## 任务控制

- 任务中心新增「停止分析」；
- 已完成结果和已发生用量保留；
- 停止后不再启动新的模型请求；
- 已停止任务与失败任务分开显示。

## 当前未开放

- 原生全书概览（v1.2.0）；
- CHG-20260728-042 调查项仍未关闭，本版本不宣称已解决。

## API Key 与隐私

StoryLens 不内置开发者个人的大模型 API Key。
用户需自行配置云端或本地模型。

## 升级说明

- 可从 v1.1.1 升级；
- 数据库迁移包含场景边界人工校正与任务取消相关字段；
- 不会删除既有书籍、章节、场景分析、阅读旅程与用量记录。
