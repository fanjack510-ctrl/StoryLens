# StoryLens v1.1.2

StoryLens v1.1.2 是针对 v1.1.1 的稳定性修复版本。

本次更新不新增新的核心分析模块，重点解决阅读旅程恢复、终态展示、结果跳转以及部分长内容分析链路中的稳定性问题。

## 主要更新

### 1. 阅读旅程中断恢复更加稳定

修复阅读旅程中断后点击“继续分析”时的多项状态问题：

- 恢复成功后自动进入阅读旅程结果；
- 不再需要手动刷新或重复点击；
- 恢复失败后明确显示“阅读旅程生成失败”；
- 失败后不再继续显示“正在恢复”或“阅读旅程已中断”；
- 避免重复创建任务、启动指令或新的分析 Run。

### 2. 修复旧状态覆盖最终结果

统一阅读旅程的当前执行状态判断：

- 已成功的阅读旅程不会再被旧的中断记录覆盖；
- 已失败的任务不会继续显示为恢复中；
- 成功或失败后不再残留进度卡；
- 主页面与右侧状态栏展示保持一致；
- 应用或本地服务重启后仍能正确恢复最终状态。

### 3. 修复“查看阅读旅程”按钮

修复右侧完成卡中的“查看阅读旅程”点击无反应问题：

- 右侧“查看阅读旅程”现在可以单击进入结果；
- 顶部“阅读旅程”和右侧入口使用同一套跳转逻辑；
- 两个入口会打开同一个 Analysis Run 和 Journey Run；
- 查看已有结果不会重新触发分析或恢复任务。

### 4. 改善结构化分析稳定性

改善长内容或复杂章节分析过程中的结构化输出处理：

- 加强模型结构化结果被截断时的处理；
- 降低不完整输出导致整个分析链路失败的概率；
- 改善错误识别和恢复过程；
- 避免旧 Revision 或旧 Journey 结果被错误复用。

### 5. 改善场景校正与确认流程

修复场景边界人工校正后的确认和启动流程：

- 人工校正结果能够进入正确 Revision；
- 重复确认不会生成多余 Revision；
- Confirm + Start 使用当前有效分析结果；
- 不再跨 Revision 复用已经完成的旧阅读旅程。

## 安装与升级

适用平台：

- Windows 10 / Windows 11；
- x64 系统。

从 v1.1.1 升级时：

1. 先退出正在运行的 StoryLens；
2. 建议备份 `%LOCALAPPDATA%\StoryLens`；
3. 运行 `StoryLens_1.1.2_x64-setup.exe`；
4. 安装完成后重新启动 StoryLens。

本版本仍使用用户自行配置的大模型 API。升级不会替代或提供模型调用额度。
